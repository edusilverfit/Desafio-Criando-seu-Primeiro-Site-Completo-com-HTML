# Desafio-Criando-seu-Primeiro-Site-Completo-com-HTML
O desafio é criar um site de uma clinica médica, com todo  o aprendizado até o momento.

# Clínica Vida Plena — Site HTML5

# Descrição 

Projeto desenvolvido como desafio: criar do zero um site institucional para uma clínica médica usando HTML5. O objetivo foi praticar marcação semântica, formulários, tabelas, mídias e boas práticas de acessibilidade e performance.

# Funcionalidades

Página estática com estrutura semântica (<header>, <main>, <footer>).

# Seções principais: apresentação, serviços, equipe, agendamento/contato e localização.

Formulário de contato com validação HTML5 (campos required, type="email", pattern).

# Uso de mídias: logo (<img>), imagem de cabeçalho e elementos multimídia quando aplicável.

Tabelas para exibir horários ou planos (uso de <table>, <thead>, <tbody>, colspan/rowspan).

# Acessibilidade básica: alt em imagens, <label> associados a inputs, aria-* quando necessário.

Responsividade básica preparada para receber CSS (layout fluido e imagens responsivas).

Tecnologias

# HTML5 (marcações semânticas, formulários, tabelas, mídia).
# CSS básico para estilo (arquivo separado opcional).
# JavaScript opcional para envio via fetch/FormData e validações adicionais.
